# Bus-ster

Bus-ster is a planned original, portrait-mode Android bus dispatch puzzle built with Flutter and Flame. It takes inspiration from the bus jam and passenger matching genre while using its own rules, levels, art, sounds, and store identity.

Start with the [step-by-step game plan](GAME_PLAN.md). The repository currently contains planning material; the Flutter app is scheduled for Stage 1.

## Repository setup

- Default working branch: `main`
- Remote: `https://github.com/dattaprasad-r-ekavade/bus-ster.git`
- Local development: Flutter, Dart, Android Studio, Android SDK

The plan records product assumptions and gates that must be validated with playtests before monetization or release.
